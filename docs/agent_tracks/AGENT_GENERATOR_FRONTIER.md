# Agent Track: Next-Generation Polytope Generator

## Mission
Turn the new profile-native / cocircuit / signed-Chow results into a complete, exact, scalable generalized-Pauli / moment-polytope generator, with rank 11 as the first genuinely new proving ground.

## Phase 1: rebase and verify current frontier
Pull current main and independently replay:
- profile-native candidate generation;
- cocircuit equivalence low-rank checks;
- signed-Chow decoder;
- known ranks 6-10 exact calibration;
- current (3,11)/(3,12) frontier artifacts;
- the Theorem S spread-cost artifact (`results/data/profile_spread_cost.json`,
  regenerated by `scripts/profile_spread_cost.py`).

## Phase 2: make the spread bound runnable
Read `docs/profile_native_generation.md` before planning this phase. The
finiteness question the original version of this track posed as "Conjecture S"
is CLOSED, and re-attacking it is wasted work:

- **Theorem S (proved, guarded by `tests/test_profiles.py`).** The pattern
  differences span `V = 1^perp n v^perp`, so `V^perp = span{1, v}` and the
  pattern set determines the values up to the reparametrization Lemma L already
  quotients out. Each rank therefore carries finitely many level vectors, level
  spread is bounded at every rank, and candidate coverage is DECIDABLE rather
  than open. Cramer and Hadamard make it explicit:
  `spread <= 2 sqrt(r-1) (N sqrt 2)^(r-2)`.
- A counterexample family of unbounded spread at fixed `d` is therefore ruled
  out. Do not go looking for one.

The surviving gap is quantitative, and it is the whole phase: the proved bound
is about `2.8e6` at `N = 3, r = 11`, five orders of magnitude above the realized
maximum of 20, and a run already costs 1,227 seconds at bound 20. So the target
is a bound that can actually be run:

`is the true maximum spread at rank d polynomial in r?`

Evidence to build on, not to re-derive:
- exact realized maxima 3, 4, 6, 10, 14 at ranks 6 to 10, from complete
  enumerations;
- the `D(W)` spread-cost ceiling restricted to `r <= 7` classes, which climbs
  roughly linearly over `W = 1..22` rather than at the exponential rate
  Theorem S permits;
- rank 11 does NOT saturate: the ladder reads 8,379 / 9,919 / 10,597 / 10,812 /
  10,859 unoriented orbits at spread bounds 12/14/16/18/20, and 16 profiles sit
  at spread exactly 20, so the realized maximum reaches the bound instead of
  sitting strictly inside it. Every rank-11 number is a lower bound, conditional
  in exactly that way.

The named route: make the multiplicity-budget argument quantitative, that is,
prove `sum_a min(m_a, N + 1) >= f(W)` for an explicit `f`. That argument is no
longer needed for finiteness and is now the natural route to a POLYNOMIAL bound.
A sharp non-polynomial answer is equally valuable. Do not let bounded-class
computations masquerade as a lower bound, and do not report a saturation plateau
as closure when the realized maximum reaches the bound that was run.

The second route out remains open and should be scoped rather than assumed:
exact inner and outer closure never needs candidate exhaustiveness, and is how
ranks 6 through 10 are already closed.

## Phase 3: determinant-stage compression
Candidate enumeration is no longer the dominant bottleneck, and the measurement
says where the new one is: the arrangement layer grows about 30x per rank
against about 4x for orbits, reaching 108,541,487 Ressayre trace survivors at
rank 11 and 3,051,122,527 at rank 12. Attack the billions-scale downstream
certification:
- orbit equivalence of determinant arrangements;
- reusable tangent determinant templates;
- Hall/matching rejection;
- modular exact screening with replayable rational/integer confirmation;
- symbolic factor reuse;
- profile-wise decomposition;
- exact non-birational rejection filters if they reduce volume safely.

Note the standing obstruction: `docs/screening_orbit_structure.md` proves
verdicts are NOT orbit invariants, so lifting the determinant verdict to the
orbit or profile level is a genuinely open problem, not an engineering task.
Measure every optimization against a fixed current-main baseline.

## Phase 4: complete (3,11)
Once candidate completeness is justified or conditionally bounded:
- generate all candidates;
- certify Ressayre/non-Ressayre status exactly;
- perform redundancy elimination;
- cross-check against all known partial families and existing certificates;
- label any residual assumptions explicitly.

## Phase 5: rank 12/13 only after architecture closes
Use higher ranks to test scalability, not as vanity milestones.
Do not ship "complete" systems without a proof of candidate completeness.
Rank 13 is reachable with `--frontier-ranks 11,12,13` but is deliberately not in
the shipped artifact; scratch numbers for it are not quoted as results.

## Phase 6: paper synthesis
Assess novelty and organize the strongest theorem stack:
- profile characterization;
- level reparametrization;
- cocircuit equivalence;
- signed-Chow uniqueness/decoder;
- block symmetry and dominance upper ideals;
- arbitrary-N extension;
- Theorem S and whatever quantitative strengthening Phase 2 produces;
- complete new rank system if achieved.

## Guardrails
- Keep discovery and verification independent where practical.
- Do not prefer an external backend if local exact verification cannot replay its claims.
- Do not optimize a stage that is no longer the bottleneck without measurement.
