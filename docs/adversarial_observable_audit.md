# Adversarial audit of certified observable manifolds

## Executive verdict

The core sufficient reconstruction theorem survived. Several broader
interpretations did not.

The strongest result that remains defensible is:

> On a fixed determinant carrier, in a fixed orbital frame, a full-rank
> pair-incidence map together with a connected collision-free two-body
> coherence graph gives an explicit rational inverse from selected 2-RDM
> entries to every pure full-support carrier state and every higher RDM.

The audit does **not** support any equivalence between failure of that
certificate and failure of complete-2RDM injectivity. It also does not support
a general theorem of global zero-crossing continuation yet.

## 1. Independent fermionic-sign regeneration

A second implementation was written from sequential bitstring creation and
annihilation operators. It shares neither the inversion-count sign routine nor
the channel-construction code used by the original generator.

It compared
\[
\langle D_a|A_P^\dagger A_Q|D_b\rangle
\]
against the published remainder-sign expression for every determinant pair,
every RDM order, and every orbital system through seven orbitals.

**Result:** 8,186,968 exact integer comparisons; zero mismatches.

A third implementation was then written against both, building each `a_p` as
an explicit `2^d x 2^d` Jordan-Wigner matrix and evaluating the element by
matrix multiplication. It shares code with neither the repository formula nor
the bitstring engine above. Through six orbitals it agrees with both on all
603,580 cases.

This strongly validates the sign convention, though it is still software
verification rather than a substitute for a written proof.

## 2. Exhaustive small-carrier counterexample search

All determinant carriers in the stated ranges were enumerated, restricted to
those with full pair-incidence column rank.

The search found no counterexample to the sufficient collision-free
reconstruction theorem.

It did find immediate counterexamples to stronger statements. For
\[
S=\{\{0,1,2\},\{3,4,5\}\}\subset\wedge^3\mathbb C^6,
\]
pair incidence has full rank, but no two-body operator connects the two
determinants. The complete 2-RDM is independent of their relative phase.
Thus weight recovery alone is insufficient, and complete order-two
non-injectivity can occur even on a pair-incidence-rigid carrier. The
mechanism is countable: a two-body operator moves at most two orbitals, and
these determinants differ in three. The same count explains the `d=6`, `N=3`,
`m=2` row, where exactly the 10 complementary determinant pairs out of 190
fail to connect.

The exhaustive counts are stored in
`results/data/adversarial_observable_audit.json`, regenerated by
`scripts/independent_adversarial_audit.py`.

## 3. Multiple-zero boundary tests

The component formula is correct only relative to a specified measured
coherence graph. If the active surviving graph has \(c\) components, that
measurement chart leaves \(c-1\) independent relative phases.

However, deleting several amplitudes can disconnect one chosen spanning tree
while alternate measured 2-RDM edges still connect the active support.
Therefore:

- a vanishing tree denominator is a chart singularity;
- disconnection of one tree is not physical non-identifiability;
- complete-2RDM injectivity must be tested from the entire surviving channel
  system, not one certificate tree.

This wording change is mandatory for the boundary theorem.

## 4. Complete linear 2-RDM system versus collision-free certificate

The audit represents each unordered coherence by independent
\(\Re X_{ab}\) and \(\Im X_{ab}\) variables and builds the complete real-linear
2-RDM channel matrix using the independent bitstring sign engine.

A connected unique-channel graph may reconstruct all coherences nonlinearly
through purity even when the complete linear channel matrix does not have full
rank. Conversely, failure of the unique graph does not prove that collided
channels or rank-one polynomial relations cannot recover the state.

These are three distinct statements and must remain separate:

1. collision-free tree certificate;
2. linear identifiability from all 2-RDM channels;
3. nonlinear pure-state injectivity of the complete 2-RDM map.

The exhaustive scan separates 1 from 2 by example rather than by argument. At
`d=6`, `N=3`, `m=3`, all 1140 pair-rigid carriers have a connected
collision-free graph, but only 960 have a full-rank complete real-linear
channel matrix. The 180-carrier gap is precisely the set on which statement 1
holds and statement 2 fails, so the two cannot be used interchangeably.

## 5. The 28 unresolved census records

The shipped order-two artifact has 28 records not covered by the
collision-free graph certificate. Across those 28 records, the artifact
reports **zero collided 2-RDM channels**.

Consequently, the proposed linear “determinacy closure” has no collided
equations to resolve and certifies **zero additional records**.

Their first connected collision-free reconstruction order remains:

- order three: 22;
- order four: 5;
- order five: 1.

This does not prove order-two non-injectivity. Nonlinear rank-one relations
could still make the complete 2-RDM map injective. The accurate status is
“unresolved at order two.”

## 7. Novelty after scrutiny

The paper should not claim invention of geometric quantum mechanics,
Hamiltonian flow on projective Hilbert space, generic determination from
marginals, or phase propagation on connected graphs.

The defensible novelty is narrower and stronger:

- exact support-combinatorial sufficient certificates;
- an explicit rational inverse using selected fixed-frame 2-RDM entries;
- a census-scale certified atlas;
- boundary defects computed from surviving observable graphs;
- constructive carrier families and composition rules;
- exact carrier-conditional higher-RDM closure and reduced dynamics;
- independent certificate artifacts.

## 8. Submission blockers

Before a theorem paper is ready:

1. prove cyclic channel collision-freedom in full fermionic detail;
2. formalize the gluing labels and graph containment;
3. state a precise multi-chart continuation theorem or label it algorithmic
   evidence;
4. test nonlinear pure-state injectivity on the 28 exceptions using polynomial
   elimination or certified numerical algebraic geometry;
5. obtain an independent human proof review;
6. consolidate all research patches into one tested repository branch.
